## ADDED Requirements

### Requirement: gerry has a generated brand family

`@ejm/tokens` SHALL ship `assets/projects/gerry/` in the project family format, generated by `scripts/gerry-assets.mjs` from the approved standing-G mark, with `generated:gerry-assets` provenance rows.

#### Scenario: The family verifies

- **WHEN** `node scripts/gerry-assets.mjs --check` runs
- **THEN** it passes only if every file and provenance row matches what the generator writes

### Requirement: Regenerating one family leaves the others unchanged

Running one family generator SHALL NOT change another family's files or the order of its provenance rows.

#### Scenario: gerry, then ui

- **WHEN** `node scripts/gerry-assets.mjs` runs and then `node scripts/ui-assets.mjs --check`
- **THEN** the ui check passes
