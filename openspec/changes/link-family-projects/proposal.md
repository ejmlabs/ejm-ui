## Why

ejmlabs has open source projects and a commercial product, gerry. The shared copy still calls ejmlabs a home for open source projects only. Every site's footer comes from `otherSites`, which lists only the four original build identities, so no ejmlabs site links ejm-ui, ejm-calm or gerry unless it keeps its own list (ejmlabs.com does). The ejm-ui gallery is published at ui.ejmlabs.com, but the registry still hides it "until the gallery host is published and verified". The owner selected a new gerry mark, the standing G, to replace gerry's pixel mascot everywhere; it needs one shared source.

## What Changes

- `@ejm/site`: add `LINKED_PROJECTS` (ejm-calm and gerry), family sites that are not built with `@ejm/site` and get no build identity, analytics or shared head. `otherSites` returns the published build identities, then the linked sites.
- `@ejm/site`: `ui` joins discovery. It has no analytics token, and `ANALYTICS_SITES` leaves out tokenless hosts, so no beacon loads on the gallery.
- `@ejm/site`: the `ejmlabs` tagline names open source projects, experiments and commercial products.
- `@ejm/tokens`: add the gerry brand family in `assets/projects/gerry/`, generated by `scripts/gerry-assets.mjs`. The generator body moves to `scripts/family-assets.mjs`, shared with `scripts/ui-assets.mjs`; the ui output is byte-identical. Provenance rows keep their place when another family regenerates.
- `@ejm/gallery`: the footer lists the other family sites from the gallery's own identity (`otherSites('ui')`), the "In use." list leaves out the gallery itself, and the layout example's sample copy matches ejmlabs.com.
- Docs: tokens README, `PROVENANCE.md` header, `ADOPTION.md` and `CHANGELOG.md`.

## Capabilities

### New Capabilities

- `project-registry`: which ejmlabs sites are build identities, which are linked, and what every footer lists.
- `brand-families`: generated project brand families in `@ejm/tokens`, including gerry's.

### Modified Capabilities

None. There are no main specs for these yet.

## Impact

- Packages: `@ejm/site` (registry, types, export, analytics map), `@ejm/tokens` (gerry assets, provenance), `@ejm/gallery` (footer, home list, layout example), the starter's home test. Scripts: `family-assets.mjs`, `ui-assets.mjs`, `gerry-assets.mjs`, `assets.mjs`.
- Consumers see the new footer links only after they pin this revision. ejmlabs.com, ejm-cli, ejm-ide and ejm-harness update their pins in their own repositories.
- Out of scope: the family sheets (they present the three tools), ejm-calm's own brand files (not merged in ejm-calm yet), gerry's product and site (changed in the gerry repository), and analytics for the gallery.
