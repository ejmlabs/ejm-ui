## Crop guidance

X can crop headers differently across screens and place the profile image over the lower-left portion. Essential copy is concentrated in the middle of the header, away from the edges and avatar overlap. The guide marks a conservative central content region and 60 px top and bottom crop bands. This is a design allowance, not a promise that every X client uses the same crop. The guide image is drawn on the Forest header, and the Sage, Forest and Paper headers share the same content region.

Upload at the supplied dimensions, inspect both desktop and mobile, and leave the image at its natural scale when possible. Keep the original logo proportional. The full wordmark is custom artwork, not typed text.

## Editing

Install Manrope and IBM Plex Mono from `fonts/`, then open the SVGs in `source/editable/` in a vector editor. Copy can be changed there. Production SVGs in `banners/` and `posts/` have outlined text for reliable rendering. The Sage set can be rebuilt with `design-kit/scripts/build-social.mjs`.

Colors: Sage `#8A9A7B`, Forest `#29443B`, Ink `#202721`, Paper `#F6F5EF`, Mist `#E8EDE3`. The themes are alternatives. Start with Sage for a consistent profile. Sage leads; Forest is a rare accent. Sage matches the website and the brand guide, while Forest suits dark contexts such as a dark placement or a single reversed panel. On Sage, use Ink for type and set "Useful things." in Forest only at headline sizes. Sage on Paper is 2.75:1, so it is for the logo and decoration only.
