# Contributing

1. Follow the [development setup](README.md#development), including the Linux terminal dependency build when needed.
2. Make the change in the package that owns it.
3. Run `npm run check` and, for visual changes, look at the gallery in light and dark at phone, laptop and ultrawide widths.
4. Keep commits small and the message plain.

Read `AGENTS.md` first. It lists the rules that every change must follow.
